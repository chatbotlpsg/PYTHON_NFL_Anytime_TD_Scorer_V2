# NFL Player Props Upload Order

1. Upload/install `nfl-player-props-trading-agents-support-plugin-v0.1.0.zip`.
2. Upload `nfl-player-props-command-center-md-package-v0.1.0.zip` to Project Knowledge.
3. Paste `NFL_PLAYER_PROPS_COMMAND_CENTER_PROJECT_INSTRUCTIONS.md` into Project Instructions.
4. Add `NFL_PLAYER_PROPS_AGENT_ROUTER_PATCH.md` near the top.
5. Upload the weekly `NFL_TRADING_AGENT_HANDOFF_*` ZIP.
6. Run `/print-nfl-player-prop-boards`.
7. For close capture, run `/capture-nfl-player-prop-close` after supplying current/close prices.
8. For postgame, run `/grade-nfl-player-props` and `/build-nfl-player-prop-recap` after results are supplied or verified.
