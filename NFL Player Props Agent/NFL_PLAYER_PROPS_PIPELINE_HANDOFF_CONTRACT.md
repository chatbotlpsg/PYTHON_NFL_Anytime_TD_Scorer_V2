# NFL Player Props Pipeline Handoff Contract

The Trading Agent expects a frozen ZIP created by the Python pipeline.

Typical required files:

```text
NFL_ALL_PLAYER_FORECAST_BOARD_YYYY-WXX.csv
NFL_PASSING_FORECAST_BOARD_YYYY-WXX.csv
NFL_RUSHING_FORECAST_BOARD_YYYY-WXX.csv
NFL_RECEIVING_FORECAST_BOARD_YYYY-WXX.csv
NFL_MARKET_LINED_PICK_BOARD_YYYY-WXX.csv
NFL_PASSING_MARKET_PICK_BOARD_YYYY-WXX.csv
NFL_RUSHING_MARKET_PICK_BOARD_YYYY-WXX.csv
NFL_RECEIVING_MARKET_PICK_BOARD_YYYY-WXX.csv
NFL_EV_PLAY_BOARD_YYYY-WXX.csv
NFL_EDGE_LEADERBOARD_YYYY-WXX.csv
NFL_OPPORTUNITY_PROP_BOARD_YYYY-WXX.csv
NFL_PRODUCTION_PROP_BOARD_YYYY-WXX.csv
NFL_REJECTION_BOARD_YYYY-WXX.csv
NFL_FINAL_BOARDS_YYYY-WXX.md
NFL_RUN_MANIFEST_YYYY-WXX.json
NFL_MODEL_METADATA.json
NFL_MARKET_SNAPSHOT_YYYY-WXX.csv
NFL_CORRELATION_MATRIX_YYYY-WXX.csv
NFL_THESIS_BOARD_YYYY-WXX.csv
NFL_PLAYER_ROLE_STATE_YYYY-WXX.csv
NFL_UNCERTAINTY_REPORT_YYYY-WXX.csv
NFL_CONVERGENCE_REPORT_YYYY-WXX.csv
NFL_DATA_LINEAGE.json
NFL_PROVIDER_HEALTH_YYYY-WXX.json
```

Missing non-critical files should produce board-specific DATA GAP notes. Missing manifest, all player forecast board, EV board, or final boards should trigger handoff review.
